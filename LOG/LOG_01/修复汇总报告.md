- **问题**：

  4. **新增 `ModManager`**（`main/mod_manager.gd`，静态工具类）：扫描 `user://mods/*`，`get_config_dirs(type)` 返回"本体 `res://config/<type>` + 各 mod `config/<type>`"，并加载 mod 自带 `.translation` 翻译。
  5. **`main.gd` 注册逻辑**改为 `_register_all_configs()`：按依赖顺序（武器 → 单位 → 建筑 → 投射物）遍历 `ModManager` 目录注册，本体优先、mod 后注册（同名可覆盖）。
- **代码段**：`extension/src/unit_loader.h/.cpp`、`building_loader.h/.cpp`、`weapon_loader.h/.cpp`、`projectile_loader.h/.cpp`、`unit_manager.cpp`、`building_manager.cpp`、`weapon_manager.cpp`、`projectile_manager.cpp`、`main/mod_manager.gd`（新增）、`main/main.gd`、`config/**/*.cfg`（22 个）。

### D. 网络与安全（4 项）

#### 12. RPC 无权限校验
- **问题**：多个 `rpc_server_*`（ANY_PEER）不校验发送者，任意客户端可：为任意队伍刷单位、指挥（含他人）单位移动/攻击、为其他队伍放置建筑、未注册即改地图/设置。
- **修改**：6 个 RPC 入口加入校验——服务器本地调用（`sender_id <= 1`）信任；远端必须已注册且通过归属校验，违规输出 `[Security]` 日志并拒绝：
  | RPC | 校验 |
  |---|---|
  | `rpc_server_receive_move` / `rpc_server_receive_attack_unit` | 已注册 + 被指挥单位全部归属其队伍 |
  | `rpc_server_request_spawn_unit` | 已注册 + `p_team` 等于其队伍 |
  | `rpc_server_request_place_building` | 已注册 + `p_team` 匹配 + `p_builder_ids` 归属其队伍 |
  | `rpc_server_set_map` / `rpc_server_update_player_settings` | 未注册远端拒绝 |
  新增辅助函数 `_units_owned_by_team()`。
- **代码段**：`extension/src/game_manager.cpp` 上述 6 个函数 + `_units_owned_by_team`；`extension/src/game_manager.h` 新增声明。
- **保留**：`rpc_server_request_produce_unit`（原本已校验队伍归属）、`rpc_server_request_registration`（必须对新玩家放开）、全部 `rpc_client_*`（AUTHORITY，仅服务器可发）。

#### 13. 主机迁移（阶段1：优雅交接）
- **问题**：房主退出时客户端收到 `server_disconnected` 即 `leave_game()`，全员退回大厅，对局丢失。
- **修改**：实现优雅迁移协议：
  1. 旧主机 `migrate_host()`：`serialize_game_state()` 打包单位/建筑/经济 → 发给继任者（`rpc_begin_migration`）→ 继任者上报地址 → 旧主机广播 `rpc_handover` 后自动 `leave_game()`；
  2. 继任者 `_become_new_host()`：`create_server` 成为 peer 1，重连的客户端 `rpc_server_rejoin(旧id)` 自报身份，新主机按 `migration_mapping` 重建 `players_settings`；
  3. 全部回归或 5s 超时后 `finalize_migration()` → `restore_game_state()` 恢复，游戏无缝继续（客户端不重载场景，靠快照恢复渲染）。
- **配套改动**：`unit_manager::clear_all_units()`、`building_manager::clear_all_buildings()`、`place_building_by_type()` 增加 `p_force` 参数（恢复时跳过 `is_area_clear`，避免被场上单位挡住）；`_physics_process`/`_process` 增加迁移门控（新主机在迁移完成前挂起模拟）；`pause_menu.gd` 房主退出前先 `migrate_host()`（有继任者才交接，否则直接退出）。
- **代码段**：`extension/src/game_manager.h/.cpp`（`migrate_host`/`serialize_game_state`/`restore_game_state`/`rpc_begin_migration`/`rpc_report_address`/`rpc_handover`/`rpc_server_rejoin`/`finalize_migration`/`pick_successor`/`_get_local_ip`/`_become_new_host`/`_reconnect_to_new_host`）、`unit_manager.h/.cpp`、`building_manager.h/.cpp`、`ui/pause_menu/pause_menu.gd`。
- **限制**：仅覆盖"房主主动退出"；硬崩溃（阶段2 checkpoint）、大厅迁移、跨 NAT 未做。

#### 14. 掉线保留 + 自动重连（替代"掉线淘汰"方案）
- **问题（新需求）**：玩家掉线后希望**一切行为保留、直到重连、期间仍可判定胜负**；原"淘汰无在线玩家队伍"的方案被否。
- **修改**：
  - **撤销淘汰逻辑**：删除 `_eliminate_abandoned_teams()`（含其在 `_on_peer_disconnected`、`finalize_migration` 中的调用）。
  - `_on_peer_disconnected()` 局内掉线：仅把玩家身份暂存到 `disconnected_players`，**实体/经济/生产全部保留**。
  - 客户端断线自动重连：`_on_server_disconnected` 非迁移且游戏中 → `_reconnect_to_host()` 重连同一主机（重试 3 次、15s 超时）；`_on_connected_to_server` 重连成功后 `rpc_server_rejoin(旧id)`。
  - `rpc_server_rejoin()` 优先从 `disconnected_players` 恢复（普通重连），其次 `migration_mapping`（迁移回归）。
  - 胜负判定未改动（建筑制），掉线期间照常每秒判定。
- **代码段**：`extension/src/game_manager.h`（新增 `disconnected_players`/`reconnecting`/`local_peer_id` 等成员、`_reconnect_to_host` 声明）、`extension/src/game_manager.cpp`（`_on_peer_disconnected`/`_on_server_disconnected`/`_on_connected_to_server`/`_on_connection_failed`/`rpc_server_rejoin`/`_reconnect_to_host`/`_process` 超时检查/`host_game`/`join_game` 记录地址）。

#### 15. 实体死亡客户端同步修复（随 #14 顺带）
- **问题**：服务器移除死亡单位/建筑时**未广播到客户端**——`_on_despawn_unit_requested`/`_on_despawn_building_requested` 只改本地；`rpc_client_despawn_unit` 只清选择、未删本地实体，导致客户端上死亡单位永久残留渲染。
- **修改**：两个 `_on_despawn_*` 在服务器侧追加 `rpc("rpc_client_despawn_unit"/"rpc_client_remove_building", id)` 广播；`rpc_client_despawn_unit` 改为真正调用 `unit_manager->despawn_unit()` 删除本地实体。
- **代码段**：`extension/src/game_manager.cpp` `_on_despawn_unit_requested` / `_on_despawn_building_requested` / `rpc_client_despawn_unit`。
