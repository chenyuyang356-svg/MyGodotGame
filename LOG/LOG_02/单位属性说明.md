# 单位属性说明（unit_reference.csv 字段详解）

> 日期：2026-08-05
> 数据来源：`the-range-of-justice/config/unit/*.cfg` 与 `extension/src/unit_stats.h`
> 配套文件：`the-range-of-justice/unit_reference.csv`（10 种单位，38 列）

CSV 的 38 列与单位配置 `.cfg` 的 key 一一对应。配置里未填写的字段取默认值（`can_fire_on_move`=false、`emit_threshold`=-1、`particle_scale`=-1、`dying_time`=1.0）。

---

## 一、标识与翻译（4 列）

| 列 | 含义 | 说明 |
|---|---|---|
| `unit_name` | 单位注册名（内部名） | 全局唯一；被建筑 `producible_units`、`spawn_unit_by_type` 等引用。如 `Tank` |
| `unit_name_key` | 显示名翻译键 | 对应 `translation/translation.csv` 的 `id`，游戏用它显示中文名。如 `KEY_UNIT_TANK` |
| `unit_tags` | 单位标签（位掩码） | 可组合：`Biological` / `Mechanical` / `Builder` / `Summoned` / `Hero`。其中 **Builder** 驱动建造/修复逻辑 |
| `producible_buildings` | 可建造的建筑列表 | 仅 `Builder` 有值，如 `Collector, HumanBarrack, Shipyard, Fortress` |

## 二、移动（8 列）

| 列 | 含义 | 单位/取值 |
|---|---|---|
| `move_type` | 移动类型 | `Ground` / `Air` / `Sea` / `Hover`，决定走哪层流场与碰撞 |
| `mass` | 质量 | 相对值，越大越"重"，碰撞时他人让开更多 |
| `move_speed` | 最大移动速度 | 世界像素/秒，如 150 |
| `acceleration` | 加速度（引擎功率） | 数值越大提速越快 |
| `turn_speed` | 转向角速度 | 弧度/秒 |
| `turn_acceleration` | 角加速度 | 弧度/秒² |
| `collision_radius` | 碰撞半径 | 世界像素，决定被点击/碰撞判定范围 |
| `base_height` | 基准高度 | **> 20 视为飞行单位**，可被对空武器攻击；地面/海上为 0 |

## 三、生存（5 列）

| 列 | 含义 | 说明 |
|---|---|---|
| `health_max` | 最大生命 | 血量归零进入死亡状态 |
| `health_regen` | 每秒自动回血 | 如 0.5 = 每秒回 0.5 |
| `shield_max` | 护盾上限 | 先扣盾再扣血（当前所有单位为 0） |
| `shield_regen` | 每秒回盾 | 当前都为 0 |
| `armor_type` | 护甲类型 | `Light` / `Heavy` / `Building` / `Hero`（当前只用 Light） |

## 四、攻击（4 列）

| 列 | 含义 | 说明 |
|---|---|---|
| `target_priority` | 索敌优先级 | `Closest` 最近 / `Lowest_hp` 最低血 / `Highest_value` 高价值 |
| `can_fire_on_move` | 是否可移动中开火 | `true` / `false` |
| `weapon` | 内联武器 | 单位自带、跟随车体朝向。格式见下方"内联武器语法"；多个用 `;` 分隔 |
| `weapon_mount` | 独立炮塔挂载 | 引用 `config/weapon/*.cfg` 已注册武器。格式：`武器名, 本地偏移X, 本地偏移Y`；多个用 `;` 分隔 |

### 内联武器（`weapon`）语法

`weapon = 投射物名, 伤害, 射程, 冷却, [弹速, 溅射, 偏移X, 偏移Y, 偏移Z, 容差, 可打地面, 可打空中]`

| 段位 | 参数 | 必填 | 默认 |
|---|---|---|---|
| 1 | 投射物名（`config/projectile/*.cfg` 的 name） | 是 | — |
| 2 | 伤害 damage | 是 | — |
| 3 | 射程 attack_range | 是 | — |
| 4 | 冷却 attack_interval（秒） | 是 | — |
| 5 | 弹速 projectile_speed | 否 | 500 |
| 6 | 溅射 splash_radius | 否 | 0 |
| 7-9 | 出生偏移 spawn_offset (X,Y,Z) | 否 | (0,0,0) |
| 10 | 开火容差 firing_tolerance（度） | 否 | 15 |
| 11 | 可攻击地面 can_attack_ground | 否 | true |
| 12 | 可攻击空中 can_attack_air | 否 | false |

### 两套武器系统的区别

| | `weapon`（内联） | `weapon_mount`（独立炮塔） |
|---|---|---|
| 写在 | 单位配置，自包含 | 引用 `config/weapon/*.cfg` 已注册武器 |
| 贴图/动画 | 无（跟随车体） | 有（炮塔独立 sprite） |
| 独立旋转 | 否（靠容差） | 是（`is_turret=true`） |
| 依赖 | 仅需投射物已注册 | 武器必须先注册（加载顺序：武器→单位） |

> 注意：武器写的 `splash_radius` 对投射物攻击**不生效**，命中溅射取的是投射物配置（`shell.cfg`/`missile.cfg` 目前 `splash_radius=0`，故当前无 AOE）。

## 五、视野（2 列）

| 列 | 含义 | 说明 |
|---|---|---|
| `sight_range` | 视野半径 | 世界像素，点亮战争迷雾 |
| `aggro_range` | 主动索敌半径 | 在此范围内自动寻敌攻击 |

## 六、经济（2 列）

| 列 | 含义 | 说明 |
|---|---|---|
| `cost` | 造价 | 金币，生产时从所属队伍扣除 |
| `build_time` | 生产耗时 | 秒，生产建筑按此时间 × `production_speed` 计算 |

> `cost`/`build_time` 是单位**被生产**的代价；生产入口在建筑侧 `producible_units`（仅 `Barracks` 类型建筑生效）。

## 七、粒子与死亡（4 列）

| 列 | 含义 | 说明 |
|---|---|---|
| `emit_threshold` | 粒子触发距离阈值 | 每移动这么多像素产生一次粒子；`-1` 用默认（陆地=1.2×半径，海上=0.5×半径） |
| `particle_scale` | 粒子全局缩放 | `-1` 用默认 |
| `effect_point` | 自定义粒子挂点 | 格式：`特效类型, X偏移, Y偏移, 缩放覆盖, 寿命覆盖, 是否波纹`；多个用 `;` 分隔。如 `Dust, -20.0, -40.0, 2.0, -1, false` |
| `dying_time` | 死亡动画时长 | 秒，默认 1.0 |

## 八、渲染与动画（8 列）

| 列 | 含义 | 说明 |
|---|---|---|
| `texture_path` | 贴图路径 | 图集（Sprite Sheet）路径 |
| `h_frames` / `v_frames` | 图集水平/垂直切分 | 图集分几列 × 几行 |
| `idle_frames` | 待机动画帧数 | 待机循环几帧 |
| `idle_row` | 待机动画所在行 | 从 0 开始 |
| `move_frames` | 移动动画帧数 | 移动循环几帧 |
| `move_row` | 移动动画所在行 | 从 0 开始 |
| `anim_fps` | 动画播放速率 | 每秒帧数，如 10 |

## 九、备注（1 列）

| 列 | 含义 |
|---|---|
| `备注` | **非配置项**，仅作定位说明，游戏不读取，可忽略 |

## 容易混淆的点

1. **`weapon` vs `weapon_mount`**：内联自包含跟随车体 vs 引用独立炮塔可独立旋转。
2. **`base_height > 20` = 飞行**：决定对空判定；与 `move_type=Air` 是两个概念（当前配置里两者一致）。
3. **生产工厂不是单位属性**：`producible_units` 写在建筑侧，单位本身没有"由谁生产"字段；且只有 `Barracks` 类型建筑（兵营/造船厂）真正产兵，`Collector` 里写的 `producible_units` 是死配置。
4. **溅射陷阱**：武器 `splash_radius` 对投射物攻击无效，需改投射物配置（见"内联武器语法"下方注释）。
