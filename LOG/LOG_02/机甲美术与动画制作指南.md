# 机甲美术与动画制作指南（Blender 3D 转 2D 像素工作流）

> **适用范围**：突击机甲 (Striker)、先锋机甲 (Vanguard)、巨神机甲 (Goliath) 及后续机甲单位的美术贴图与步态动画生产。  
> **核心工具链**：Blender (3D建模/IK步态/渲染) ➔ Aseprite (修线/团队色Alpha遮罩/图集导出) ➔ Godot 引擎 (`.cfg` 配置 & `unit_shader` 渲染)。

---

## 一、 为什么采用“3D 预渲染转 2D 像素”工作流？

在 2D/2.5D 顶视角（Top-Down）像素 RTS 游戏中，机甲相比坦克和飞行器有极高的绘制门槛：
1. **多关节联动与透视变形**：手绘双足/四足走动极易出现肢体忽大忽小、关节错位和“滑步”问题。
2. **多朝向与工作量爆炸**：如果纯手绘序列帧，单套机甲往往需要数天。
3. **分层解耦需求**：机甲需要底盘（腿部走动）与上半身（武器旋转瞄准）分离。

**3D 预渲染核心优势**：
- 用 3D 彻底解决**结构透视、骨骼联动与步态物理**，保证透视 100% 准确且无滑步。
- 零高模/零复杂手绘贴图要求，仅用基础几何体拼装即可。
- 单个机甲的完整走动动画可在 **1~2 小时内高效产出**。

---

## 二、 完整制作流水线（Step-by-Step）

```
[Blender 积木低模] ➔ [简易骨骼 + IK 步态动画] ➔ [正交相机极低分辨率渲染]
                                                       ↓
[Godot 引擎接入]   ⬅ [导出 Spritesheet / Alpha 254] ⬅ [Aseprite 后期微调]
```

### 第一步：Blender 积木式建模（零雕刻、零复杂贴图）

由于最终输出为 32px ~ 64px 像素，模型表面细节过多会形成噪点，只需保证“剪影形准”。

1. **结构拆分**（在 Blender 中分为两个独立 Object）：
   - **底盘对象（Base）**：包含骨盆（Pelvis）、大腿（Thigh）、小腿（Shin）、脚掌（Foot）。
   - **武器/上半身对象（Turret）**：包含驾驶舱/躯干（Torso）、肩甲（Shoulder）、武器炮管（Cannon/Gun）。
   > **注**：渲染时可分别隐藏另一个对象，独立导出底盘动画与武器贴图。
2. **材质赋予（纯色色块）**：
   - 无需展开复杂 UV，直接使用 Blender 基础材质赋予纯色：
     - **主装甲色**：中灰/军绿/冷灰（基础涂装）。
     - **机械关节色**：深灰/黑铁色（液压管、关节球）。
     - **团队色占位色**：亮洋红色/高亮纯色（方便识别装甲板位置）。
     - **发光点**：自发光材质（驾驶舱目镜、喷口）。

---

### 第二步：简易骨骼与反向动力学（IK 极速步态）

使用 IK（反向动力学）只需移动脚底控制器，大腿和小腿便会自动自然折叠弯曲。

```
          [Pelvis 骨盆] (根骨骼，负责上下微幅颠簸)
            /        \
       [L_Thigh]   [R_Thigh]
           |           |
       [L_Shin]    [R_Shin]
           |           |
       [L_Foot]    [R_Foot]
           ↑           ↑
     (IK 控制器: Foot_IK_L / Foot_IK_R)
```

1. **骨骼绑定**：
   - 建立单骨架（Armature），按层级延伸至脚掌，使用自动权重或刚性父子级绑定。
2. **添加 IK 约束**：
   - 在小腿（Shin）骨骼上添加 `Inverse Kinematics` 约束。
   - `Target` 指向脚底独立的控制器骨骼 `Foot_IK`，`Chain Length（链长）` 设为 `2`。
3. **8 帧标准行走循环关键帧设计**：
   - **第 1 帧【接触帧 Contact】**：左脚在前着地，右脚在后蹬地，骨盆居中。
   - **第 3 帧【下沉收腿 Down/Pass】**：左脚全掌支撑承重，右脚离地向前收回，**骨盆 Z 轴微幅下移 1 个单位（表现重量感）**。
   - **第 5 帧【反向接触 Contact Opp】**：右脚向前跨出着地，左脚在后蹬地。
   - **第 7 帧【反向下沉 Down/Pass】**：右脚全掌支撑，左脚离地向前收回，骨盆下移。
   - **第 9 帧**：复制第 1 帧（循环闭合，渲染导出 1~8 帧）。

---

### 第三步：Blender 相机与像素化渲染配置

1. **正交相机（Orthographic Camera）**：
   - 相机类型选择 `Orthographic`。
   - 角度调整为项目统一视角（顶俯视 90° 或 倾斜俯视 45°~60°）。
2. **渲染分辨率设置（按机甲吨位匹配像素）**：
   - **突击机甲 (Striker)**：`32 × 32 px`
   - **先锋机甲 (Vanguard)**：`48 × 48 px`
   - **巨神机甲 (Goliath)**：`64 × 64 px`
3. **消除抗锯齿与模糊（保证像素边缘锐利）**：
   - 渲染引擎：`Eevee` 或 `Cycles`。
   - **胶片透明**：`Render Properties` ➔ `Film` ➔ 勾选 `Transparent`。
   - **像素滤镜（关键）**：`Film` ➔ `Pixel Filter` ➔ `Filter Width` 调到最小值 `0.01`（或使用 Box 滤镜），避免半透明羽化模糊。
4. **灯光设置**：
   - 使用单一日光（Sun Light），从左上方照射（如旋转 X: 45°, Y: -30°, Z: 45°），营造统一的顶光阴影。
5. **输出序列帧**：
   - 输出格式：`PNG`，颜色：`RGBA`，色深：`8-bit`。
   - 导出为序列帧文件：`striker_walk_01.png` ~ `striker_walk_08.png`。

---

### 第四步：Aseprite 后期处理与项目规范

1. **导入与去噪**：
   - Aseprite 打开第一张序列帧图片，自动导入为动画。
   - 用铅笔工具清理杂散孤立像素点，在向光面边缘点缀 1 像素高光。
2. **设置团队色遮罩（匹配 `unit_shader.gdshader` 规则）**：
   - **着色器判定规则**：Alpha 值在 `0.994 ~ 0.998`（对应 8-bit Alpha 通道值为 **`254`**）的像素，会被运行时动态替换为玩家所属队伍颜色。
   - **处理方法**：
     - 在 Aseprite 中将装甲外壳、肩部盖板等预定染色区域的像素，将其颜色属性中的 **Alpha（不透明度）手动修改为 `254`**（普通像素为 255）。
     - 染色面积建议控制在机体面积的 15%~25%，避免全身变色丢失机械层次。
3. **导出精灵图集（Sprite Sheet）**：
   - 菜单选择 `File` ➔ `Export Sprite Sheet`。
   - Layout 方式选择 **By Rows（横向单行）**。
   - 导出路径例如：`res://asset/unit/striker_mech.png`。

---

### 第五步：Godot 配置文件接入

以突击机甲为例，在 `the-range-of-justice/config/unit/striker_mech.cfg` 中配置：

```ini
;########################################
; 突击机甲配置文件 (StrikerMech)
;########################################

unit_name = StrikerMech
unit_name_key = KEY_UNIT_STRIKER_MECH

; --- 生存与护盾属性 ---
health_max       = 80.0
health_regen     = 0.5
shield_max       = 60.0
shield_regen     = 2.0
armor_type       = Light

; --- 武器挂载 (上半身独立旋转) ---
weapon_mount = StrikerBlaster, 0.0, 0.0
can_fire_on_move = true

; --- 移动与物理 ---
mass             = 2.0
move_speed       = 160
acceleration     = 120
collision_radius = 16
move_type        = Ground

; --- 渲染与动画定义 (对应导出的图集) ---
texture_path = res://asset/unit/striker_mech.png
h_frames = 8
v_frames = 1

idle_row = 0
idle_frames = 1        ; 静止时停留在第 1 帧
move_row = 0
move_frames = 8        ; 移动时播放 8 帧行走循环
anim_fps = 10
```

## 四、 实用技巧与常见问题排查

1. **如何彻底避免“太空步 / 滑步”感？**
   - 走动动画的移动速度与物理移速需匹配：`步长(像素) × 动画FPS ≈ 移动速度(move_speed)`。
   - 支撑脚在着地期间，在世界坐标中应保持绝对静止，仅骨盆向前平移。
2. **巨神机甲四足动画简化秘诀**：
   - 四足机甲无需做复杂的重心摆动。采用 **对角交替步态**（1号左前腿 + 4号右后腿先走；2号右前腿 + 3号左后腿后走），只需 4 个关键帧即可呈现极强的机械稳定感。
3. **免费低模资源推荐**：
   - **Kenney.nl**（Space Kit / Asset Forge）：大量可商用 CC0 几何零件。
   - **Sketchfab / itch.io**：搜索 `Low Poly Mech Kit` 获取基础零部件并自由拼接。
4. **脚步落地粒子加持**：
   - 在机甲配置文件中配置 `unit_particle`，在脚掌落地时喷射微量尘土粒子，能极大掩盖低分辨率下步态细节的微小瑕疵，显著增强机械踩踏打击感。
