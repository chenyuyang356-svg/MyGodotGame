# 机甲单位设计文档（Striker / Vanguard / Goliath + 机甲工厂）

> 日期：2026-08-05
> 状态：已实现（含新增的护盾/回复机制）
> 设计目标：三个机甲单位均带**可缓慢回复的护盾**；按小型/中型/重型递进；新增机甲工厂负责生产。

## 一、设计总览

| | 突击机甲 StrikerMech | 先锋机甲 VanguardMech | 巨神机甲 GoliathMech |
|---|---|---|---|
| 定位 | 快速远程输出 | 多武器 + 溅射 + 对空 | 笨重、护盾血量双回复、大溅射、对空 |
| 造价 / 建造 | 400 / 14s | 900 / 20s | 2000 / 35s |
| 护盾上限 / 回盾 | 60 / 2.0 | 120 / 3.0 | 250 / 4.0 |
| 生命 / 回血 | 80 / 0.5 | 150 / 0.5 | 300 / 3.0 |
| 移速 | 160（快） | 120 | 60（笨重） |
| 射程 | 450 | 500（主炮） | 650 |
| 移动开火 | 是 | 是 | 否 |
| 溅射 | 无 | 有（40） | 有（90） |
| 对空 | 否 | 是 | 是 |

## 二、三个单位详情

### 1. 突击机甲 StrikerMech（小型机甲）
- **攻速快、伤害低、范围稍大、无溅射**
- 护盾：`shield_max=60`，`shield_regen=2.0`
- 生存：`health_max=80`，`health_regen=0.5`，`armor_type=Light`
- 移动：`Ground`，`move_speed=160`，`acceleration=120`，`mass=2.0`，`collision_radius=36`
- 视野：`sight_range=400`，`aggro_range=400`
- 武器：`StrikerBlaster`（弹速2500 的快速光束，伤害20，射程450，冷却0.8，无溅射，对地）
- `can_fire_on_move=true`

### 2. 先锋机甲 VanguardMech（中型机甲）
- **伤害较高、可挂载多种武器、有溅射、可对空**
- 护盾：`shield_max=120`，`shield_regen=3.0`
- 生存：`health_max=150`，`health_regen=0.5`，`armor_type=Light`
- 移动：`Ground`，`move_speed=120`，`acceleration=90`，`mass=5.0`，`collision_radius=44`
- 视野：`sight_range=450`，`aggro_range=500`
- **双武器**（体现"多种武器"）：
  - 主炮 `VanguardCannon`（伤害35，射程500，冷却1.2，溅射40，**对地对空**）
  - 副炮 `VanguardAA`（伤害12，射程400，冷却0.5，无溅射，**仅对空**防空机枪）
- `can_fire_on_move=true`

### 3. 巨神机甲 GoliathMech（重型机甲）
- **笨重、可恢复护盾和血量、火力猛、溅射大、可对空**
- 护盾：`shield_max=250`，`shield_regen=4.0`
- 生存：`health_max=300`，`health_regen=3.0`（快速回血），`armor_type=Heavy`
- 移动：`Ground`，`move_speed=60`，`acceleration=40`，`mass=15.0`，`collision_radius=60`
- 视野：`sight_range=500`，`aggro_range=550`
- 武器：`GoliathCannon`（伤害120，射程650，冷却3.5，溅射90，对地对空）
- `can_fire_on_move=false`（笨重，停下开火）

## 三、护盾/回复机制（本次新增实现）

**背景**：此前 `shield_max` / `shield_regen` / `health_regen` 只是配置字段，代码从未使用（无 `current_shield`、伤害直扣生命、无回复逻辑）。

**本次实现**：
1. `UnitData` 新增 `current_shield`；`spawn_unit` 初始化 `current_shield = shield_max`。
2. 伤害结算（单体 `apply_damage` 与范围 `apply_aoe_damage`）**护盾优先吸收**，溢出部分扣生命。
3. `physics_update`（服务器权威）每帧回复：护盾按 `shield_regen`/秒、生命按 `health_regen`/秒，均不超过上限。
4. 快照同步 `current_shield`（单位段每单位 +4 字节，广播/接收同步更新）。
5. 血条合并显示 `(护盾+生命)/(护盾上限+生命上限)`。

**平衡影响提示**：回复逻辑对所有单位生效，现有单位配置里 `health_regen=0.5` 将真正生效（此前是死字段）；机甲通过更高的 `shield_regen`/`health_regen` 凸显回复优势。

## 四、机甲工厂建筑（新增）

- 配置名：`MechFactory`，翻译键 `KEY_BUILDING_MECH_FACTORY`（机甲工厂）
- `building_type=Barracks`（复用产兵逻辑），`placement=land`
- `cost=600`，`build_time=20`，`health_max=1500`
- `footprint=2,2`，`clearance=3,3`（大型工厂）
- `producible_units=StrikerMech,VanguardMech,GoliathMech`
- 建造者 `Builder` 的 `producible_buildings` 追加 `MechFactory`

## 六、贴图与动画建议
