# 地图网格 256→16px 修改报告

> 日期：2026-08-05
> 分支：`vibe-coding`
> 说明：本次只改"非单位/建筑数据"的部分；单位与建筑的数值由你根据重画后的贴图自行设定，未在本报告范围内。

## 一、改了什么

### 1. 瓦片集格子尺寸 256 → 16
- `asset/tileset/tile_set.tres`：
  - `texture_region_size = Vector2i(256,256)` → `Vector2i(16,16)`
  - `tile_size = Vector2i(256,256)` → `Vector2i(16,16)`
- 地图 `.tscn` 的格坐标不变，每个格子的世界尺寸从 256px 变为 16px。

### 2. 源码硬编码兜底 → 16（7 处）
| 文件 | 行 | 改动 |
|---|---|---|
| `extension/src/attack_manager.cpp` | 45, 806, 997 | `Vector2(256.0f,256.0f)` → `Vector2(16.0f,16.0f)` |
| `extension/src/building_manager.cpp` | 260, 479 | `Vector2(32,32)` → `Vector2(16,16)` |
| `extension/src/projectile_manager.cpp` | 65, 263 | `Vector2(32,32)` → `Vector2(16,16)` |

> 这些兜底只在 `flow_field_manager` 为空时用到（实际会被覆盖），统一改 16 保持一致性、防止误用。

### 3. FlowFieldManager 新增 3 个可调属性（替换原先的硬编码常量）
- 新增成员 + 绑定 + 检查器属性：
  - `max_search_dist`（默认 60）——替换 `find_nearest_walkable_cell` 里的 `MAX_SEARCH_DIST=30`；格子变小后按"格"的世界搜索距离从 7680px 降到约 960px（16px 格下足够）
  - `density_blur_radius`（默认 1）——密度均值模糊改为**可调半径的盒模糊**（原固定 5 邻域十字），0 表示不模糊
  - `path_safe_zone_radius`（默认 2）——替换 `is_path_traversable` 里的 `SAFE_ZONE_RADIUS=1`；格子变小后调大到 2，保持目的地安全区世界尺寸

### 4. 新增集中调参文件 `main/game_tuning.gd` + `main/game_tuning.tres`
在 Godot 编辑器中**双击 `main/game_tuning.tres` 即可改所有可调参数**，开局时 `main.gd` 自动写入 C++ Manager。

| 分组 | 参数 | 默认 | 作用 |
|---|---|---|---|
| 单位物理 | `flow_factor` | 2000 | 流场引导力 |
| | `separation_factor` | 100 | 单位排斥力 |
| | `separation_limit` | 250 | 排斥力上限 |
| | `separation_radius_factor` | 3.0 | 排斥探测半径 |
| | `lateral_separation_factor` | 1.0 | 侧向排斥 |
| | `friction_factor` | 20 | **摩擦力（越大停越快）** |
| | `force/velocity_threshold_squared` | 0.0 / 1.0 | 力/速度阈值 |
| | `desired_integration` | 0.5 | 期望集成值 |
| 流场 | `density_weight` | 0.3 | 密度代价权重 |
| | `density_decay_factor` | 0.2 | 密度衰减 |
| | `max_density_cost` | 100 | 密度代价上限 |
| | `max_search_dist` | 60 | 找最近可走格半径（格） |
| | `density_blur_radius` | 1 | 密度模糊半径（格） |
| | `path_safe_zone_radius` | 2 | 直线检测安全区（格） |
| 地形 | `near_obstacle_radius` | 2 | 近障碍检测半径（格） |

### 5. `main/main.gd` 接入调参
- 顶部 `const Tuning = preload("res://main/game_tuning.tres")`
- 开局 `Tuning.apply_to(unit_manager, flow_field_manager)` 写入全部参数
- 地形初始化里近障碍检测半径改用 `Tuning.near_obstacle_radius`（原硬编码 ±1 格）

## 二、由你处理/补充的事项

1. **单位/建筑数值**：`config/unit/*.cfg` 与 `config/building/*.cfg` 的 `collision_radius`/`footprint`/`move_speed` 等，按你重画后的贴图自行设定（碰撞直径 ≈ 贴图宽，32px 单位 → 半径 ≈15）。
2. **Tileset.png 需按 16px 重切/重绘**：目前只改了网格尺寸，`Tileset.png`（原 1280×1280 的 256px 瓦片）会被按 16px 重新切片显示成碎块——**必须重画 16px 瓦片**，否则地图贴图是错乱的。
3. **瓦片自定义数据**：`tile_set.tres` 里 `IsWall/IsSea/IsResource` 三个自定义层及其瓦片标记保留不变。

## 三、验证

- `scons` 增量编译通过（FlowFieldManager 等重编链接成功）。
- Godot 无头运行主场景：无脚本/资源/加载报错，GameTuning 正常加载并应用，16px 格子正常建立。

## 四、建议的调参入口

- **贴墙/避边**：改 `main/game_tuning.tres` 的 `near_obstacle_radius`（地形初始化时生效，需重开一局）。
- **单位聚集/停靠**：`separation_factor`、`friction_factor`、`separation_radius_factor`。
- **寻路搜索范围/密度**：`max_search_dist`、`density_weight`、`density_blur_radius`、`path_safe_zone_radius`。
- 这些参数**进入游戏场景时应用**；改 `.tres` 后重新开始一局即可生效。
